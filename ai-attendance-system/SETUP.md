# Admin Pre-Setup
1. You may want to seed the first admin user using a POST request or SQL insert:
   ```json
   POST http://localhost:8000/admin/register
   { "name": "Admin", "email": "admin@example.com", "password": "password" }
   ```
2. Login to the unified dashboard, add students, upload training images, and then hit "Train AI Model".

## Requirements
- Python 3.10+
- Node.js 18+

## Run Locally

### 1. Backend (FastAPI + OpenCV)
```bash
cd backend
python -m venv venv
# Windows
venv\Scripts\activate
# Linux/Mac
source venv/bin/activate

pip install -r requirements.txt
uvicorn main:app --reload
```

### 2. Frontend (React + Vite)
```bash
cd frontend
npm install
npm run dev
```

## Run via Docker
```bash
docker-compose up --build
```
The Frontend will be at `http://localhost`, the Backend API at `http://localhost:8000`.

## API Documentation
The API documentation is automatically generated by FastAPI.
When running locally:
- Swagger UI (Interactive): `http://localhost:8000/docs`
- ReDoc (Alternative): `http://localhost:8000/redoc`
